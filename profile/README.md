# Welcome 👋

We build practical, reliable tools that help people work smarter, automate repetitive tasks, and manage modern digital systems with less friction.

## What We’re Working On

- **Agentic systems** for automating research, development, operations, and repetitive browser-based workflows
- **Home lab and infrastructure projects** using Kubernetes, Rancher, Longhorn, Unifi, Raspberry Pis, mini PCs, and cloud services
- **AI-powered productivity tools** for email, knowledge work, and personal operations
- **Web and SaaS experiments** focused on useful automation, clear workflows, and real-world deployment

## Core Focus Areas

- AI-assisted software development
- Infrastructure automation
- Self-hosted services
- Workflow orchestration
- Email and knowledge management
- WordPress, web apps, and SaaS platforms
- Cloud, hybrid, and home lab deployments

## Principles

We prefer systems that are:

- Useful before they are flashy
- Secure by default
- Easy to operate
- Well documented
- Built for real people, not demos
- Capable of growing from home lab experiments into production services

## Current Direction

Our work is centered on building reliable AI-enabled tools and infrastructure that can support personal productivity, small business operations, creative projects, and scalable software products.
